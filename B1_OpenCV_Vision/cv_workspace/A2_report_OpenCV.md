# A2_report_OpenCV
## 核心代码说明
### 实现人脸坐标获取
``` 
faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5)
//模型在灰度图找脸，结果存在faces里
//输入：灰度图像（gray），图像每次缩小的比例（scaleFactor），最低重叠票数（minNeighbors）
//输出：faces是一个二维数组，里面是若干个[x,y,w,h]
//滑窗（拿一个固定大小的“人脸模板”，在图上从左到右、从上到下扫）
缩放（把原图缩小 1.1 倍，再扫一遍，循环直到图太小为止）
投票（把扫出来的重叠框合并，重叠数超过 5 个的，输出为最终坐标）
print(f"共检测到 {len(faces)} 个目标") 
```
### 局部区域截取
```
face_roi = img[y:y+h, x:x+w]
//原图像切片
//输入：原图像矩阵（img），目标框左上角坐标（x,y）,右下角坐标
//输出：截取出来的局部图像矩阵 face_roi(h, w, 3)
//先按行切出高度 h，再按列切出宽度 w，交叉的那块矩形就是结果
```
### 模糊替换
```
blurred = cv2.GaussianBlur(face_roi, (99, 99), 0)
//用99*99的高斯核模糊原图像切片
img[y:y+h, x:x+w] = blurred
//输入：局部切片，原图
//输出：局部被打码后的原图 img
//逻辑：先算出模糊块，再原位“贴”回原图
```

## 问题解答
**penCV 读取的彩色图像在内存中本质上是什么数据结构？其 shape 属性的三个维度分别代表什么?**

三维数组，高宽通道。

**图像裁剪与局部区域模糊在底层数组层面对应什么操作？**

图像裁剪：对应 多维数组的切片

局部区域模糊：
卷积运算（Convolution）：在切出的子数组上，用一个 99×99 的矩阵（核）做滑动窗口的加权平均。
数组赋值（Assignment）：把算出的新子数组，按原索引写回（覆盖） 原图的对应切片位置。
